`exercises_es_slim.json` contiene los 1.324 registros suministrados para Pulso Fit. `exercises_featured.json` selecciona 60 ejercicios iniciales para distribuirlos en las rutinas. `exercise_names_es.json` contiene los nombres en español para esa selección; el resto del catálogo recibe una etiqueta española basada en el grupo muscular al importarse.

Los pasos de ejecución ya están en español. `media_id` se conserva, pero `media_url` se mantiene nulo hasta configurar un proveedor cuyas condiciones permitan el uso comercial y la carga desde el dominio de despliegue.
